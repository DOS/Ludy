# Social media covers

These are cover and header images for Ludy's social profiles. They use the brand mark (`../ludy-mark.svg`) and the brand colors (purple `#612BD3` and `#44209A`, green `#0A6A5B`). Their text reads "Ludy", "AI-native Business OS", "For one-person companies and small businesses in Vietnam" and "ludy.so".

| File | Where it goes | Size | Note |
|---|---|---|---|
| `linkedin-cover-1128x191.png` | LinkedIn company page banner | 1128 x 191 | One row, left to right, starting right of the page logo, which overlaps the lower left; "for solo founders & SMEs in Vietnam" |
| `linkedin-cover-4200x700.png` | The same banner, high resolution | 4200 x 700 | LinkedIn's larger recommended size |
| `facebook-cover-1640x624.png` | Facebook page cover | 1640 x 624 | The content stays in the center, which is safe on both phone and desktop crops |
| `x-header-1500x500.png` | X (Twitter) header | 1500 x 500 | The text is placed clear of the profile photo |
| `youtube-banner-2560x1440.png` | YouTube channel banner | 2560 x 1440 | The content sits in the 1546 x 423 area that every device shows |
| `og-image-1200x630.png` | Link preview image (Open Graph) | 1200 x 630 | |

For a profile photo or logo, use `../ludy-icon-512.png` (512 x 512) or `../ludy-mark.svg`.

All files are PNG without an alpha channel. They were rendered from HTML in Chromium, with no stock images or fonts outside the system set. To change the text or the layout, render them again the same way.
